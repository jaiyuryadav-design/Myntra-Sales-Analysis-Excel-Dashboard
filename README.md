# Myntra Sales Analysis - Excel Dashboard

## 📌 Project Overview

This project presents an interactive Excel dashboard developed to analyze Myntra sales data. The objective is to transform raw order and return data into meaningful business insights using data cleaning, Pivot Tables, KPIs, and interactive visualizations.

The project contains three main dashboards:

- Revenue Dashboard
- Sales Dashboard
- Product Performance Dashboard

## 📊 Dashboard Overview

### 1. Revenue Dashboard
Provides an overview of revenue-related performance and helps analyze financial trends across the dataset.

### 2. Sales Dashboard
Provides insights into overall sales performance, including:

- Total Sales: ₹24,17,654
- Total Orders: 5,250
- Monthly Sales Analysis
- State-wise Sales
- Brand Performance
- Order Status Analysis

### 3. Product Performance Dashboard
Analyzes product-level performance to identify:

- Top Performing Products
- Product-wise Sales
- Brand Performance
- Discount Analysis
- Product Categories and Article Types

## 🛠️ Tools & Techniques Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- KPI Cards
- Slicers
- Excel Formulas
- Data Visualization
- Dashboard Design

## 📂 Dataset

The project includes order, return, and order-flow data that was cleaned and transformed before creating the final analysis and dashboards.

## 🎯 Project Objective

The objective of this project is to analyze e-commerce sales data and create an interactive Excel dashboard that helps understand sales trends, revenue performance, product performance, customer orders, returns, and regional performance.

## 💡 Key Insights

The dashboard helps identify:

- Overall sales and order performance
- Monthly sales trends
- High-performing brands and products
- State-wise sales contribution
- Distribution of order statuses
- Product performance patterns
- Revenue and return trends

## 📁 Project File

`Myntra_Sales_Analysis_Dashboard.xlsx`

The Excel workbook contains the cleaned data, Pivot Tables, KPI calculations, and all three interactive dashboards.
